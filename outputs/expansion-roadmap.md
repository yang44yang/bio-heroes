# Bio Heroes 扩容路线图 —— "季 / 资料片"机制

> 写于 2026-06-28。目标：把"扩卡"从零散加卡，升级成一个**可持续、有节奏、像赛季/资料片**的机制。
> 研究基础：Marvel Snap / Hearthstone / LoR / Pokémon Pocket 的发版节奏 + MTG 的 set 设计哲学（New World Order 复杂度预算、Storm Scale、稀有度=频率非战力、横向不纵向）+ 教育游戏研究（内在整合、图鉴完成度心理、主题包=课程单元、"巧克力裹西兰花"陷阱）。来源见文末。

---

## 0. 一句话结论

**别再"想到哪加到哪"。改成：每季度发一个有名字的"季"（资料片），每季 = 1 个新机制 + ~20 张主题卡 + 图鉴完成度奖励 + 战役章节 + 标题屏换肤。** 兴奋感来自"新生物 + 新机制 + 新主题"，**不是更大的数值**——这同时避开了行业最大的两个坑：数值膨胀（power creep）和内容跑步机疲劳（content treadmill）。对一个"一个爸爸 + 一个 AI"的团队，**季度节奏比月更节奏更可持续**（参考 Balatro 单人开发者主动放慢避免 crunch）。

---

## 1. 现状盘点（真实数据，2026-06-28）

- **生物卡 124 张**：nature 45 / body 27 / pathogen 26 / tech 26。
- **扩展包 set**：BASE 104 / OCEAN 11 / MICRO 9 —— 扩展包**全是 nature**（OCEAN 11 全 nature，MICRO 9 里 8 nature + 1 body）。
- **稀有度**：R 56 / SR 42 / **SSR 26（占 21%）** ← ⚠️ 偏高。行业惯例 SSR/传说 ~5–15%，应往单/低双位数收。
- **费用曲线**：1–3 费 74 张（偏胖），6 费以上仅 18 张，0 费仅 4 张。早期偏挤、终盘偏薄。
- 配套：SP 17 / 事件 16 / 进化链 2。
- 既有系统资产（可被"季机制"复用）：阵营标记、SP 三触发、环境事件、进化链、状态系统（**已有 poison / sleep / stealth / shield / immune / deep_pressure 深海压力**）。

**三个要在扩容里修的结构问题**：
1. **扩展包阵营失衡**：body/pathogen/tech 几乎没吃到扩展包 → 未来季优先补这三系。
2. **稀有度通胀**：SSR 21% → 新卡守 ~50% R / ~35% SR / ~15% SSR。
3. **数值纪律**：扩卡必须横向（同战力档新花样），不能纵向（更大数字）。

## 2. 还有多大空间？——生物领域几乎"无限"

生物学的可卡化领域远超现有卡池。按"一个领域 = 一个主题季"粗分，至少有 **10+ 个富矿区**（研究指出真菌 / 极端生物 / 共生 / 深海热泉 / 分解者循环 是"几乎没人做过"的高差异化区）：

| 领域富矿 | 例 | 天然机制钩子 |
|---|---|---|
| 海洋生态 / 共生 | 深海、珊瑚礁、清洁站、小丑鱼-海葵 | 深海压力、共生配对 |
| 微观 / 单细胞 / 细胞零件 | 草履虫、硅藻、核糖体、线粒体 | 分裂增殖、能量主线 |
| 人体 / 免疫 | 先天 vs 适应、记忆细胞、抗体 | 免疫记忆 |
| 病原 | 病毒/细菌/真菌/寄生虫 | 传染、潜伏 |
| 远古 / 演化 | 恐龙、三叶虫、寒武纪、megafauna | 进化适应、大灭绝 |
| **真菌王国** | 蘑菇、霉菌、地衣、菌丝网 | 菌丝网络、分解回收 |
| **极端生存** | 水熊虫、管虫、嗜盐菌、再生(蝾螈) | 隐生/再生 |
| 生态危机 / 保护 | 食物网、关键种、入侵种、濒危 | 营养级、连锁崩溃 |
| 植物专题 | 食虫植物、巨杉、防御、传粉 | 扎根、毒素、网络 |
| 动物超能力 | 毒、电、回声、速度记录、群体 | 各种专属 |

**务实量级**：现有 124 张。按每季 ~20 张、8 个季 → **+~170 → ~300 张**（2 年内、季度节奏）。这是"质量优先、可持续"的目标，不是把 CLAUDE.md 里那张 ~640 的远景表一次堆完。**预留空间足够，瓶颈是设计/平衡/出题的工时，不是题材。**

## 3. 行业参考（浓缩，可直接套用的硬规则）

**发版节奏（数字参考）**
- HS：大资料片 ~135–145 张 / 4 个月 + 中期 mini-set ~38 张；LoR：旗舰 ~89 张 + 两个 ~40；Pokémon Pocket：大包 ~220 / 主题包 ~95，**每月有动静**。
- **规律 > 体量**：玩家追的是"心跳节奏"（每月/每季有事），不是单次卡海。**大主推 + 小填充**交替，别"一次性巨量然后沉默"。
- **小团队现实区间**：季度（~3 个月）一个"季"，~15–25 张。**承诺一个你能稳住一年的节奏**——破坏既定节奏比慢更伤信任（LoR 砍 PvP 翻车）。

**Set 设计（复杂度纪律）**
- **每季只加 1 个（最多 2 个）新机制/关键词**，其余复用常青词。复杂度是流失新人的头号杀手。
- MTG「New World Order」硬尺子（直接适配 7 岁）：常见卡 **≤ 11 字规则文本**；**~80% 低稀有卡保持简单**（甚至留一部分纯数值"白板"）；阅读难度压到 ~小学低年级；**confusing 关键词只放高稀有**（孩子先学会基础再遇到）。
- **稀有度 = 出现频率 + 复杂度 + 花哨度，≠ 战力**。CLAUDE.md 已经把 cost 和 rarity 解耦了，把这条纪律延伸到"战力跨稀有度大致拉平"。
- **横向不纵向（grow wide, not tall）**：新卡给"同战力档的新玩法"，不是更大数字。配 **Escher 楼梯**：这季把某处抬一点、别处压一点，整体天花板保持平。
- **Storm Scale**：常青（每季都在：守护/迅击…）+ 落叶（偶尔回归的老朋友）+ 每季 1 个签名一次性机制（给这季身份）。

**教育设计（这是我们的护城河）**
- **内在整合（Intrinsic Integration）**：知识必须长在核心机制里。litmus test：**"一个孩子能不能完全无视生物学就赢这局？"能 → 这张卡的技能要重设计。** 水熊虫的免伤*就是*极端生存这堂课。
- **图鉴完成度**是 7 岁最强留存钩子。用**预存进度效应**：新季图鉴别从 0% 开始，先送头几张，让"3/8 已收集，还差 5 张"显眼地拉着走。
- **主题包 = 课程单元**（Genius Games 的 Cytosis/Ecosystem 已验证）：一个海洋季就该是一堂海洋生态课——**让图鉴凑齐的是一条完整食物链/系统**（生产者→草食→掠食→顶级），收集的过程*就是*在拼装这个结构。
- **躲开"巧克力裹西兰花"**：答题/知识必须和当前这张卡相关；奖励要绑游戏后果（答对→ATK×2 改变战局，我们已经这么做，保持）；scienceCard 要*解释刚用到的技能*，不是甩一条无关 fact。

## 4. 核心机制：可复用的「季 / 资料片」模型

### 4a. 一个"季"交付什么（5 件套，缺一不可的"赛季感"）
1. **主题 + 一条科学主线**（一个生物领域 = 一堂课）。
2. **1 个签名机制**（新关键词，必须有生物学锚点；其余复用常青词）。
3. **~20 张主题卡**（守稀有度/费用曲线纪律；图鉴凑成一个完整小系统）。
4. **图鉴完成度奖励**（预存进度；凑齐解锁：季节头像/卡背/1 张专属 SP 或大卡）。
5. **战役章节 + 标题屏/UI 换肤**（让这段时间"看起来"就不一样——这块最便宜、最出"新季"感）。

> 关键洞察：**"赛季感"主要由 主题 + 1 机制 + 奖励轨 + 换肤 扛起来，不需要上百张卡。** 现有 OCEAN/MICRO 那种 ~8 张小批，是"迷你迷你包"；把 2–3 批 + 1 机制 + 奖励轨**打包成一个有名字的季**。

### 4b. 每个季的制作流水线（7 步，每季照走一遍 = "扩容机制"）
1. **定主题 + 锚定那条科学第一性原理**（一句话）。
2. **定 1 个签名机制**（生物锚点；先想"遮住卡名能不能猜出生物"）。
3. **和齐齐一起选生物清单 + 主线食物链/系统**（确保图鉴凑成完整结构）。
4. **设计卡**：数值/技能/稀有度/费用曲线——守纪律（~50/35/15 的 R/SR/SSR；复杂技能只上 SR/SSR；R 卡简单、留几张白板；横向不纵向；优先补缺的阵营）。
5. **配 3 层题（记忆/机制/推理）+ scienceCard（解释技能）**。
6. **引擎接线 + 图鉴/奖励 + 战役章节 + 季主题 UI**。
7. **平衡校验 + 测试 + 齐齐实测 + 收尾**（沿用现有 `scripts/test-*.mjs` 惯例 + preview）。

## 5. 路线图：8 个季（+1 收官）——这就是那"6–10 步"

> 每季 1 个签名机制（生物锚点），优先补失衡阵营。卡数 ~20（终章 ~16）。机制尽量复用/扩展已有系统资产。

| # | 季名（资料片） | 主题 / 科学主线 | 签名机制（1 个新关键词） | 阵营焦点 | ~卡 | 图鉴主线 / 钩子 |
|---|---|---|---|---|---|---|
| **S1** | 🌊 海洋深渊 OCEAN（补完） | 深海高压 / 共生 / 食物链 | **深海压力 Deep Pressure**（低费卡在场受压削弱，深海/高费卡免疫——已有 `deep_pressure` status 雏形） | nature·海洋 | 11→~24 | 凑一条海洋食物链（硅藻→磷虾→…→抹香鲸/虎鲸） |
| **S2** | 🔬 微观战场 MICRO（补完） | 单细胞 / 细胞零件 / 能量起源 | **分裂增殖 Replication**（细菌二分裂/出芽：每隔回合复制一个弱化体——已有大肠杆菌 Binary Fission 雏形） | nature微生物 + body细胞零件 | 9→~24 | 拼一条能量主线（蓝细菌→叶绿体→线粒体→眼虫→管虫） |
| **S3** | 🛡️ 人体奥秘 BODY（免疫战争） | 免疫系统：先天 vs 适应、记忆 | **免疫记忆 Immune Memory**（被某阵营攻击后对其获永久抗性/加伤——教疫苗/适应性免疫） | **body**（补零） | ~24 | 组"免疫小队"（中性粒/巨噬→T/B/抗体/记忆细胞） |
| **S4** | 🦠 瘟疫纪元 PATHOGEN | 病毒/细菌/真菌/寄生虫致病 | **传染 Contagion / 潜伏 Latency**（每回合感染相邻或随机敌方，潜伏后爆发——教传播/潜伏期） | **pathogen**（补零） | ~24 | 集齐四类病原 + 可做敌方 Boss 池 |
| **S5** | 🦖 远古生命 ANCIENT | 恐龙/寒武纪/巨型生物/活化石 | **进化适应 Adapt**（卡存活 N 回合后"进化"变强；大灭绝环境事件——教自然选择，扩进化链系统） | nature史前 + 跨阵营 | ~24 | 复活一条演化树（7 岁最爱恐龙，吸引力拉满） |
| **S6** | 🍄 真菌王国 FUNGI | 蘑菇/霉菌/地衣/菌丝网/分解者 | **菌丝网络 Mycelial Network**（真菌卡互相连线越多越强；分解者回收死卡能量——教营养循环 / wood-wide-web） | 新 subType fungus | ~20 | 铺一张菌网（**研究指出最未开发的差异化卖点**） |
| **S7** | 🧊 极端生存 EXTREME | 极端环境 / 超能力动物 / 再生 | **隐生·再生 Cryptobiosis/Regen**（强化版免伤+复活但有代价——已有水熊虫/海星/孢子雏形） | 跨阵营"奇葩" | ~20 | 视觉/趣味爆点（毒/电/深潜/再生） |
| **S8** | 🌍 生态危机 ECO | 食物网 / 关键种 / 入侵种 / 保护 | **营养级 Trophic Level**（卡按食物链层级计价；移除关键种→连锁崩溃——借鉴 Ecologies，整合现有环境事件） | 跨阵营生态 | ~20 | 维持一张稳定食物网；教育升华到保护 |
| **S9**（收官） | 🏆 传说 LEGEND | 跨域传奇生物 + 生物学里程碑 | 复用已有机制的"组合大招"（不加新机制，收束复杂度） | 跨阵营 | ~16 | 全图鉴里程碑奖励 |

**为什么是这个顺序**：先补完已起步的 OCEAN/MICRO（沉没成本最低、最快出一个完整季）→ 再用 BODY/PATHOGEN 补阵营失衡 → ANCIENT 接住恐龙这个 7 岁超级吸引力 → FUNGI/EXTREME 打差异化/趣味 → ECO 收口到生态与保护的教育升华 → LEGEND 收官。**S1–S2 是"练手季"**（机制都有雏形），跑顺流水线后再上更重的 S3+。

## 6. 必须守住的纪律（贯穿所有季）

1. **稀有度收口**：新卡 ~50% R / ~35% SR / ~15% SSR；SSR 占比往下压（现 21% 偏高）。R 卡简单，留几张纯数值白板。
2. **复杂度预算**：每季只加 1 个新机制；复杂/confusing 关键词只上 SR/SSR；R 卡描述短（向"≤11 字 / 小学低年级"靠）。
3. **横向不纵向**：新卡 ≈ 同战力档，靠"新生物 + 新玩法"出彩，绝不靠更大数字。Escher 楼梯保持天花板平。
4. **阵营平衡**：未来季优先喂 body / pathogen / tech（扩展包至今 100% nature）。
5. **内在整合 litmus**：每张卡过两关——"遮住卡名能猜出生物吗" + "无视生物学也能赢吗→重设计"。
6. **scienceCard 解释技能**，不甩无关 fact；答题与当前卡相关；奖励绑战局后果。
7. **节奏承诺**：选一个能稳住一年的节奏（建议季度一个季），稳定兑现 > 激进追量。保护开发者（爸爸+AI）不 crunch。

## 7. 立刻可做的小事（低成本、先于 S1）

- **图鉴加"每包完成度"追踪 + 预存进度**：`X/Y 已收集`，新季先送头几张让进度条不从 0 起（心理学已验证近翻倍完成率）。这是单点最高杠杆的留存改造（改 Collection/图鉴）。
- **稀有度体检**：扫一遍现有 26 张 SSR，挑明显过量/越位的考虑降级或转 SR（缓解通胀，给未来季留空间）。
- **季 UI 骨架**：标题屏可换"当前季"主题色/插画 + 一个"本季解锁"占位（卡背/头像）——为 S1 起做最便宜的"赛季感"地基。
- **每季一个 `set` 常量 + dex 分组**（OCEAN/MICRO 已有 set 字段，扩展到 dex 分组展示即可）。
