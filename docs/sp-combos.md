> 速查：哪张事件卡能召出哪些 SP、最早第几回合。配合卡组构建（DeckBuilder）用。

## 一、SP 怎么被召唤出来（机制）

SP 卡**不能从手牌打出**，必须在战斗中触发。当前实现里，触发的唯一方式是：**打出一张带「🌟可触发SP」的事件卡**。一次成功召唤要同时满足：

1. 打出一张带 `spSummonRule` 的**事件卡**（消耗它的费用）；
2. **战场有空位**；
3. 那张 SP **在你的 SP 卡组里**（5 张名额）；
4. 满足**召唤回合门槛**（看 SP 费用，见第二节）；
5. 满足该事件卡**自己的条件**（阵营 / 费用上限 / 弃牌数 / 能量，见第三节）。

> ⏳ 设计文档另有「连续答对2题 / 主人HP≤50% / 第8回合」三条触发（Phase B），当前**尚未实现**；现阶段 SP 只靠事件卡触发。

## 二、召唤回合门槛（看 SP 费用）

公式 `spEarliestSummonTurn = max(3, spCost − 3)`（`deckRules.js`）。小 SP 第 3 回合可召，大 SP 自然推迟：

| SP 费用 | 最早可召回合 | 代表 SP |
|---|---|---|
| 5 / 6 | **第 3 回合** | CAR-T · 超级细菌 · 纳米 · 霸王龙 · 骨骼巨人 · 生物膜 |
| 7 | 第 4 回合 | 大脑 · CRISPR · 大王乌贼 · 疫苗之盾 |
| 8 | 第 5 回合 | 远古病毒 · 远古世界树 · 免疫风暴 · 盖娅复苏 |
| 9 | 第 6 回合 | 丧尸瘟疫 |
| 10 | 第 7 回合 | 量子医疗 |

> 第 1-2 回合**一律召不出**任何 SP（地板挡早期甩 SP）。

## 三、触发事件卡分三类（共 16 张，12 张可触发 SP）

### 🟢 同阵营·无视费（faction_only，`maxCost=99`）
**召出该阵营任意费用的 SP**——这是"低费秒大SP"的关键。

| 事件卡（费） | 召出 |
|---|---|
| 🌱 食物链爆发(2) | 任意**自然系** SP |
| 🧬 抗原呈递(2) | 任意**人体系** SP |
| 🦠 基因突变(2) | 任意**病原系** SP |
| ⚗️ 紧急手术(3) | 任意**科技系** SP |

### 🔵 任意SP（discard_check / spend_all_energy，`maxCost=99`）
满足"弃牌/能量"后，**全部 17 张 SP 任挑、不限阵营**。

| 事件卡（费） | 条件 |
|---|---|
| ⚗️ 科技革命(5) | 弃牌堆 **2 张**科技卡（门槛最低）|
| 🌱 物种大爆发(4) | 弃牌堆 3 张自然卡 |
| 🧬 干细胞分化(4) | 弃牌堆 3 张人体卡 |
| 🦠 全球大流行(5) | 攒能量 ≥ 该 SP 费用 |

### 🟡 费用限制（cost_limit）— 不限阵营，但只召小 SP
| 事件卡（费） | 召出 |
|---|---|
| 🦠 抗药性进化(3) | 任意 spCost ≤ **6** 的 SP |
| ⚗️ 临床试验(2) | 任意 spCost ≤ **5** |
| 🌱 生态恢复(3) | 任意 spCost ≤ **5** |
| 🧬 发烧反应(2) | 任意 spCost ≤ **5** |

### ⚪ 无触发（只有普通效果）
🌱 光合作用 · 🧬 免疫应答 · 🦠 感染爆发 · ⚗️ 实验观察

## 六、平衡说明

- **看费用门槛**让"低费秒巨兽"自然延后：基因突变→丧尸瘟疫 要到第 6 回合，不再是第 3 回合无脑甩。
- **阵营厚度不均**：自然/病原/人体在抽卡池都有 28000-30000 的大 SP；**科技抽卡池最强只有 CRISPR 16000**——科技的两张大 SP（量子医疗/疫苗之盾）是通关解锁卡。所以纯抽卡时科技偏弱，需靠通关补强。
- **discard_check / cost_limit 不限 SP 阵营**：阵营只是"钥匙"，凑齐后能召任意阵营 SP，是泛用 splash 工具。
