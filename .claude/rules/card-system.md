# 卡牌系统

## 卡牌类型

| 类型 | 说明 |
|------|------|
| 生物卡 | 主力战斗卡，有 ATK / HP 两项基础属性 + 技能 |
| SP觉醒卡 | 条件触发后从 SP 卡组翻出，逆转战局 |
| 环境事件卡 | 战斗中自动触发，影响场上所有生物 |

## 卡牌属性

每张生物卡包含：
- **卡名**（完整中文名，如"蚂蚁军团·觅食狂潮"）
- **阵营**：自然系 nature 🌱 / 人体系 body 🧬 / 病原系 pathogen 🦠 / 科技系 tech ⚗️
- **能量费用 cost**：0-10（与稀有度独立）
- **稀有度 rarity**：R / SR / SSR（与费用独立）
- **ATK**：攻击力
- **HP**：生命值（归零被击败）
- **技能**：基于真实科学属性（技能列表见下方）
- **科学知识卡**：一段有趣的科学事实
- **进化链**（部分卡牌）
- **子类型 subType**：阵营内的细分分类（如自然系下分 plant/land/marine/aerial/micro）
- **扩展包 set**：所属扩展包（当前全部为 "BASE"，后续扩展为 OCEAN/MICRO/BODY 等）
- **标签 tags**：额外标签数组（用于真实生物分类学标注和未来筛选，如 ["bird", "raptor"]）

> **注意：没有 DEF 和 SPD 基础属性。** 防御和速度相关能力全部通过技能实现，与 Card Warriors 一致。

## 四大阵营系统

### 阵营划分

| 阵营 | 代号 | 包含内容 | 定位 |
|------|------|---------|------|
| 🌱 自然系 | nature | 植物（向日葵、大树、藻类）+ 动物（蓝鲸、金鹰、蚂蚁、水熊虫） | 大自然的力量 |
| 🧬 人体系 | body | 细胞（白血球、T细胞、红血球、神经元）+ 器官（心脏、大脑、肺、骨骼、肌肉） | 人体内的战士 |
| 🦠 病原系 | pathogen | 病毒、细菌、寄生虫（流感病毒、大肠杆菌、疟原虫等） | 反派！入侵者！ |
| ⚗️ 科技系 | tech | 药物（抗生素、疫苗）、技术（CAR-T、CRISPR）、工具（显微镜） | 人类的科技武器（后期扩展） |

### 阵营克制（⏳ 具体克制关系和数值待与孩子一起设计）

阵营之间存在克制关系，克制方攻击被克制方时获得伤害加成。
具体哪个阵营克制哪个阵营、加成比例多少，将在后续与孩子一起讨论确定。

设计方向参考：
- 人体系 克制 病原系（免疫系统对抗病原体）
- 科技系 克制 病原系（抗生素/疫苗消灭病原体）
- 病原系 克制 自然系？（瘟疫摧毁生态？）
- 以上仅为候选方向，最终由父子共同决定

### 同系协同增益（⏳ 待与孩子一起设计）

场上 5 张卡全为同一阵营时触发特殊增益。
具体每个阵营的增益效果待定。

## 子类型系统（SubType）

子类型是**游戏玩法分组**，不是严格的生物分类学。
真实分类通过 `tags` 字段和 `scienceCard` 标注。

| 阵营 | 子类型 | 代号 | 包含 | 分类学注意 |
|------|--------|------|------|-----------|

| | 海洋生物 | marine | 蓝鲸、虎鲸、章鱼、水母、鲨鱼... | — |
| | 飞行生物 | aerial | 金鹰、蝙蝠、蜂鸟... | 蝙蝠是哺乳动物，tags 加 "mammal" |
| | 微生物 | micro | 草履虫、水熊虫、变形虫... | 草履虫 tags 加 "protist"，水熊虫加 "tardigrade" |
| 🧬 人体系 | 血液免疫 | blood | 白血球、红血球、血小板、抗体... | Phase 3 可能拆分 blood + immune |

## 卡牌版本系统

同一个生物可以有多个版本，每个版本是**不同的卡**（不同卡名）：
- "蚂蚁军团"和"蚂蚁军团·觅食狂潮"是两张不同的卡
- 同一张卡（按完整卡名判定）最多在卡组中放 3 张
- 不同版本的科学知识卡讲述该生物的不同方面
- 卡牌版本设计使用**专门的卡牌设计工具**进行，不在 CLAUDE.md 中逐一罗列
